# SteelSeries Audio Core

- Project manages PipeWire/WirePlumber DSP configurations, Bluetooth codecs (SBC-XQ), and profile switching for SteelSeries Arena 7 / Series 7 speakers.
- Contains a main Python CLI and a Bash MPRIS watcher daemon.
